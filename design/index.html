Tokens

Two surfaces. The editor chrome never changes. The site theme is built only from these tokens, and every site owner can edit its palette and type scale.

Chrome colors

  • Graphite#1B1F24Text, icons, pressed switches, every focus ring, the mark
  • Steel#56606BSecondary text, hints
  • Rule#7E8690Control borders, 3:1 on every chrome surface
  • Alloy#DCE0E5The bench behind trays and page
  • Key#E9ECEFTiles and pressable surfaces
  • Plate#F4F5F7Top bar, trays, dialogs
  • White#FFFFFFContent only: the page and fields
  • Tool yellow#EDC200The accent: the work in hand, and Publish. Always with graphite edges; graphite text on it 9.7 to 1.
  • Error#B3261EErrors, delete
  • Retrying#8A5800Warnings, on Warning tint
  • Warning tint#FBDA8EConflict banner. Amber, never cream.
  • Live#1E7B4APublished marker; half filled while changes are not live

The accent is one variable, --mark: every mark in the editor reads it, the top-bar mark and this chip included. On white it is only 1.7 to 1 by itself, so it never stands alone: lines carry graphite keylines, thin lines are graphite, and text on it is graphite. It is a color no other page builder wears: pink and magenta, purple and violet, the default blues, black, a shop-builder green.

Site palette slots

Six slots the site owner can change in Site style. Every widget takes its colors from these, never from a hex value.

  • AaTextInk, #14302A
  • AaBackgroundPaper, #FFFFFF
  • AaPrimarySea, #1E5B4C
  • AaAccentBuoy, #F2A541
  • AaSoftShallows, #E6EFEA
  • AaMutedSlate, #4E625B

Each slot offers curated tones only, and Site style checks their contrast in words. Primary: Sea #1E5B4C, Harbour #1D4E6F, Kelp #3B5A23, Basalt #4A4F57. Accent: Buoy #F2A541, Cap pink #F4A0B5, Sea glass #9FD3C1, Lemon #F6D55C.

Illustrations are images and keep their own colors: Sky #DCE7E4, First light #E9DDD7, Mist #E7E9EA, Dawn #F2D3C6, Dawn deep #E8B4A0, Sun #F7C97A, Haze #9DB1A8, Glint #B7CFC5, Sea pale #8FB3A4, Sea mid #5E8E7D, Sea deep #3F7A68, Rock #5E6B66, Rock light #7C8883, Stone #B9C1BC, Concrete #D5DAD7, Cap pink #F4A0B5.
